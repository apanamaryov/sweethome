# Карточка обзора «поток энергии» — дизайн

Версия: 2026-08-01. Статус: **дизайн согласован с пользователем в визуальном компаньоне**
(итераций макета — 19; финал: `.superpowers/brainstorm/4158577-1785594900/content/flow-variant-v19.html`,
аварийные состояния — v12–v17).

## 1. Цель

Заменить строчную карточку инвертора на странице обзора (`/`) диаграммой потоков
энергии в духе экранов Deye: инвертор в центре, вокруг — солнце, сеть, батарея и
нагрузка-дом; видно направление движения энергии и кто сейчас питает дом.
Стиль — родной e-ink (бумага, печатные цвета, инлайн-SVG, без внешних ассетов).

## 2. Компоновка карточки

- Карточка остаётся `section.card.home-card` на `/` (регресс-гард «не Panel» сохраняется).
- **Кликабельна вся карточка** → `/inverter` (обёртка `<Link>` блочного вида; `cursor: pointer`,
  при hover — тонкий outline). Ссылки «Відкрити» и шеврона нет.
- Шапка — существующий стиль `card-head`/`card-title` («Інвертор») + hairline; **бейджа
  источника нет**. В особых состояниях справа, в конце строки после hairline — чип
  состояния (см. §5).
- Тело — инлайн-SVG диаграмма (`viewBox="0 0 320 250"`, ширина 100%):
  - центр — символ инвертора: скруглённый корпус (rx 4), тонкая диагональ, в DC-углу «⎓»
    (сплошная + пунктирная линии), в AC-углу синусоида; все пути со скруглёнными стыками;
  - узлы по углам: **солнце** (охра `--sun`, верх-лево), **сеть** (слива `--plum`,
    верх-право, иконка высоковольтной опоры: мачта, траверса с подвесами, X-решётка),
    **батарея** (мох `--moss`, низ-лево), **нагрузка** (грифель `--slate`, низ-право,
    иконка домика с крышей-свесом и дверью);
  - узел = цветной диск r16 со **светлой иконкой** (штрихи `--paper-0`); неактивный узел —
    серый диск (`--paper-2`, обводка `--hairline`), приглушённые подписи.

## 3. Потоки и подсветка

- Ветки: солнце→инвертор, сеть→инвертор, инвертор↔батарея, инвертор→нагрузка.
  Активная ветка — цвет узла, «марширующие штрихи» (`stroke-dasharray: 3 5`,
  SMIL `<animate attributeName="stroke-dashoffset" from="0" to="-16" dur="0.9s">`
  внутри path — обновление 2026-08-01: мобильный Safari не гоняет CSS-keyframes
  по stroke-dashoffset на SVG, SMIL работает нативно); **path рисуется от
  источника к приёмнику**, штрихи текут по направлению энергии. Неактивная ветка —
  серый пунктир без анимации. Ветка батареи при заряде направлена **к** батарее.
- **Правило свечения**: узел-источник светится, когда фактически отдаёт мощность —
  солнце при `pvPower > 0`, сеть при `mainsPower > 0`, батарея при `batteryPower < 0`
  (разряд). Одновременно может светиться несколько узлов. Свечение — два размытых слоя
  под диском (`feGaussianBlur stdDeviation` 7 и 3; opacity 0.30 / 0.45) цветом узла.
- ~~`@media (prefers-reduced-motion: reduce)` — анимация штрихов отключается~~ —
  отменено 2026-08-01: направление потока и есть смысл диаграммы, а включённое на
  телефоне «Уменьшение движения» гасило её целиком; SMIL медиазапросу не подчиняется.

## 4. Подписи узлов

Формат: label (uppercase 10px, muted; у активного — ink + bold) и значение
(13px bold, deep-цвет узла). Дробные ватты округляются `fmt(v, 0)`.

| Узел | Label (i18n) | Значение |
|---|---|---|
| Солнце | новый ключ `flowSun` (uk «Сонце», ru «Солнце», en «Solar») | `X% · Y Вт`; % = `pvPower / pvPeakW`; если `pvPeakW` не задан — только `Y Вт` |
| Сеть | `cardGrid` («Мережа») | `mainsPower` Вт; при отсутствии сети (`gridVoltage < 100 В`) — кирпичное «немає» (ключ `flowGridAbsent`: uk «немає», ru «нет», en «none») |
| Батарея | `cardBattery` | `SOC% · ±Вт` (`batteryCapacity`, `batteryPower` со знаком: + заряд, − разряд) |
| Нагрузка | `cardLoad` | `X% · Y Вт`; % = `acOutputActivePower / info.acOutputRatingActivePower`; если `info` ещё нет — только `Y Вт` |

Снапшот отсутствует → в теле карточки `t.connecting`, как сейчас.

## 5. Особые состояния

Чип в шапке: `inline-flex`, иконка-треугольник (инлайн-SVG, 11px) + слово, uppercase
10px, скруглённый бордер 5px, компактные отступы.

| Состояние | Условие | Вид |
|---|---|---|
| **Байпас** | `mode === "Bypass"` | Янтарный чип «Байпас» (ключ `flowChipBypass`; палитра охры: текст/рамка `--sun-deep`/`--sun`, подложка светло-янтарная). Корпус инвертора светится янтарным ореолом, обводка `--sun-deep`. Ветка сеть→инвертор и инвертор→нагрузка активны |
| **Перегруз** | `outputLoadPercent > 100` (или `acOutputActivePower > rated`) | Значения и label нагрузки кирпичом, диск нагрузки кирпичный (`--brick`) |
| **Авария** | `mode === "Fault"` | Кирпичный чип: «Перевантаження» (`flowChipOverload`), если среди активных fault-битов есть overload, иначе «Аварія» (`flowChipFault`). Корпус инвертора — кирпичная обводка + кружок «!» в углу; все ветки idle; нагрузка «0 Вт»; если компонент помнит последнее ненулевое значение (`useRef`) — «0 Вт · було N» (ключ `flowWas`: uk «було», ru «было», en «was») |
| **Сеть отсутствует** | `gridVoltage < 100` | Узел сети серый, значение — кирпичное «немає» |

## 6. Конфигурация: пик PV-массива

- `InverterConfig.pvPeakW` — новый параметр, env **`INVERTER_PV_PEAK_W`** (`envInt`,
  default `0` = не задан → на карточке у солнца только ватты).
- Прокидывается в `ApiMeta` (`/api/inverter/meta`, optional поле `pvPeakW`) → web `useMeta()`.
  `packages/inverter-mcp/src/testing/fake-gateway.ts` и типы `ApiMeta` обновить синхронно.
- На Pi добавить в `server/.env`: `INVERTER_PV_PEAK_W=5160` (12 панелей × 430 Вт) —
  **вручную**, deploy.sh файл `.env` не трогает.

## 7. Реализация (границы)

- Новый компонент `web/components/InverterFlow.tsx` (+ `InverterFlow.test.tsx`):
  чистый рендер от пропсов `{ snapshot, pvPeakW }`; вся логика активности/свечения —
  маленькие чистые функции в том же файле, покрытые тестами.
- `web/app/(app)/page.tsx` — карточка: шапка + чип, `<InverterFlow>`, Link-обёртка.
- CSS — в `globals.css` рядом с `.home-card` (классы `.flow-*`); дизеринг не нужен,
  свечение — SVG-фильтры.
- Словарь: ключи из §4–§5 во все три языка; существующие `cardGrid`/`cardBattery`/`cardLoad`
  переиспользуются.
- Тесты страницы `/` обновляются (изменится разметка значений); регресс-гарды: не-Panel,
  href на `/inverter`, правило свечения (несколько источников), байпас-чип, «немає» без сети.

## 8. Вне скоупа

- Дашборд `/inverter` не меняется.
- HA/MQTT, MCP-инструменты — без изменений (кроме optional-поля в `ApiMeta`).
- Карточки будущих модулей на обзоре.
